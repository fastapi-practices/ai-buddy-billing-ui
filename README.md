# AI Buddy Billing UI

为 AI Buddy 计费插件提供后台运维页面，包含用量与账单、模型价格（含 models.dev 价格同步、峰谷时段与上下文阶梯价）、用户账户余额与流水、消费预算四个独立子页面，金额按后端展示币种配置换算展示

## 插件类型

- 前端插件

## 配置说明

无需额外环境变量或前端运行时配置

安装前请确保后端 AI Buddy 插件和 AI Buddy Billing 插件已启用，并已完成对应菜单和权限配置

## 使用方式

1. 安装并启用后端 AI Buddy、AI Buddy Billing 插件和本前端插件
2. 在根级菜单进入“AI Buddy 计费”，其下包含“用量与账单”“模型价格”“账户与流水”“消费预算”四个子菜单
3. 在“模型价格”按供应商和模型新增价格版本，维护生效时间、单价、峰谷时段与上下文阶梯价；同一供应商与模型只允许一条未失效价格，已存在时请直接修改；可选“保底价”（供应商 0 + 模型 `*`）为未匹配到模型价格的用量兜底
4. 价格页可先预览 models.dev 报价差异（支持按同步状态筛选、按供应商/模型搜索、按供应商限定同步范围、分页查看），确认后再应用同步，默认不覆盖人工维护的价格
5. 在“账户与流水”按用户查询账户列表，列表行内或工具栏可为指定用户充值、调整余额；点行内“账户流水”在抽屉中查看该用户的充值、消费、调整和退款流水
6. 在“消费预算”按用户和运行、对话、日、月或总量窗口配置 USD 与 token 上限
7. 在“用量与账单”查看费用汇总和用量账本（含推理输出、音频 token 与结算时命中的倍率/时段/阶梯），需要时手动触发用量归集；后台也会每分钟自动归集一次

## 卸载说明

- 卸载插件后，建议同步移除 AI Buddy 计费菜单（含四个子菜单）和权限
- 如业务已依赖余额、流水或账单页面，请先完成结算和数据导出
- 已配置保底价时，删除保底价前请确认仍有模型价格覆盖实际用量
