# AI Buddy Billing UI

为 AI Buddy 计费插件提供后台运维页面，包括模型价格版本、用户账户余额与流水、消费预算，以及用量账本、费用汇总和用量归集

## 插件类型

- 前端插件

## 配置说明

无需额外环境变量或前端运行时配置

安装前请确保后端 AI Buddy 插件和 AI Buddy Billing 插件已启用，并已完成对应菜单和权限配置

## 使用方式

1. 安装并启用后端 AI Buddy、AI Buddy Billing 插件和本前端插件
2. 在独立的“AI Buddy 计费”菜单进入计费页面
3. 在“模型价格”按供应商和模型新增价格版本，维护生效时间、单价与失效时间；新增价格后上一版价格自动失效，可修改单价或失效时间，未被账本使用的价格可以删除
4. 在“账户与流水”按用户查询账户余额，在列表行或顶部按钮为指定用户充值或调整余额，并查询充值、消费、调整和退款流水
5. 在“消费预算”按用户和运行、对话、日、月或总量窗口配置 USD 与 token 上限
6. 在“用量与账单”查看费用汇总和用量账本，需要时手动触发用量归集；后台也会每分钟自动归集一次

## 卸载说明

- 卸载插件后，建议同步移除 AI Buddy 计费菜单和权限
- 如业务已依赖余额、流水或账单页面，请先完成结算和数据导出
